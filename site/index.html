Installation & Quickstart

Prerequisites: Node.js >= 24.0.0, Git >= 2.25 (for resolve-anchor and tarball-vs-Git parity), and Antigravity >= v1.5.13 for native plugin hooks. No mandatory API keys or MCP variables are required.

Antigravity (CLI, App & IDE Extensions)

agy plugin install https://github.com/hynko431/Coldpin-npx-Safe-Finder
agy plugin list
agy --agent coldpin-auditor

Or download the SLSA-attested coldpin-antigravity.zip + SHA256SUMS.txt from GitHub Releases, unpack it, and install the folder with agy plugin install ./coldpin-antigravity.

Standalone CLI & Local stdio MCP Server (npm or Git)

# Run Coldpin MCP server via npm (zero install script execution)
npx --ignore-scripts coldpin@1.5.0 mcp

# Inspect a package cold in memory
npx --ignore-scripts coldpin@1.5.0 inspect semver@7.7.1

# Batch-screen up to 50 direct dependencies in package.json
npx --ignore-scripts coldpin@1.5.0 audit-batch ./package.json --limit 50

See full multi-harness instructions (Antigravity, Claude Code, Codex CLI, Official MCP Registry) in docs/harnesses.md and docs/getting_started.md.

Antigravity Native Plugin Architecture

Validated cleanly with agy plugin validate --strict (findings: []): 3 skills, 7 read-only agents, 3 rules, 1 local MCP server, and 3 lifecycle hook groups.

Skills 3

  • skills/coldpin/ — Canonical cross-harness skill + 5 modular aspect playbooks under references/aspect-*.md.
  • /coldpin-audit — Antigravity slash workflow for cold package vetting, manifest triage, and confusion audits.
  • /coldpin-incident — Antigravity slash workflow for patient-zero bisect, rollback anchor recovery, and regulatory notification windows.

Read-Only Aspect Agents 7

  • coldpin-auditor (mainAgent: true) — Primary read-only orchestrator delegating across 6 specialists.
  • 6 isolated background subagents (inheritCustomizations: false, commandExecutionPolicy: "off"): coldpin-discoverer, coldpin-inspector, coldpin-manifest-auditor, coldpin-confusion-auditor, coldpin-forensics, and coldpin-compliance.

Rules 3

  • rules/AGENTS.md — Always-on policy (<= 1,800 bytes) with compact 6-aspect delegation routing table.
  • rules/coldpin-manifest-guard.md — trigger: glob on package.json, lockfiles, and .npmrc.
  • rules/coldpin-incident-checklist.md — trigger: model_decision for compromise triage and disclosure timers.

Lifecycle Hooks 3

  • coldpin-npx-guard — Blocks unvetted or obfuscated npx/pnpx/bunx/yarn dlx/curl | sh runs; forces user confirmation on exact-pinned Coldpin commands.
  • coldpin-config-guard — Forces user confirmation on edits to .npmrc, package.json, lockfiles, and policy/hook files.
  • coldpin-delegation-guard — Gates dynamic define_subagent calls requesting write tools. Pure ES2020 (lib/hook.mjs), exits 0, never emits auto-approval.

Local stdio MCP Server 1

  • Zero mandatory variables — plugin starts enabled immediately upon install.
  • 7 read-only eager tools (1,563 tokens total), timeoutSeconds: 300, isolated ${PLUGIN_DATA} cache.
  • Opt-in enterprise private-registry overlay template at examples/mcp_config.private-registry.example.json.

Human Approval Boundary Fail-Closed

  • Coldpin never runs untrusted package install scripts or binaries.
  • Untrusted package prose is isolated as data with hidden/bidi Unicode and prompt-injection checks.
  • Every audit ends with a Title + Info + Evidence card listing observations, inferences, and unknowns.

Security, Privacy & Enterprise Configuration

Zero Telemetry & Local-Only Execution: Coldpin operates no hosted backend, analytics collector, or external database. Offline mode (--offline or COLDPIN_OFFLINE=1) performs zero outbound network calls and fails closed.
Environment Variable Required Description
COLDPIN_POLICY_PATH No Path to operator-pinned immutable .coldpin.policy.json.
COLDPIN_ALLOWED_ROOTS No OS-delimited workspace root allowlist for local file/tarball/Git access.
COLDPIN_AUDIT_LOG No Path to optional append-only hash-chained audit.jsonl.
COLDPIN_OFFLINE No Set to 1 to enforce offline fail-closed execution (blocks all outbound requests and remote clones).
COLDPIN_PRIVATE_SCOPES No Comma-separated internal @scope list routed exclusively to the private registry (never sent to public npm or OSV).
COLDPIN_PRIVATE_REGISTRY_URL No HTTPS-only private registry URL for COLDPIN_PRIVATE_SCOPES (SSRF IP-blocked).
COLDPIN_REGISTRY_TOKEN No (Secret) Optional read-only bearer token sent strictly over HTTPS to the exact matching private host. Unexpanded ${VAR} placeholders are rejected.
