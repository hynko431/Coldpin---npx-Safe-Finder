## Continuous Integration & Release Gates

- **Cross-Platform GitHub Actions CI (`.github/workflows/ci.yml`):** Executes `npm run verify:all` and checks `git diff --exit-code` on both `ubuntu-latest` and `windows-latest` (`fail-fast: false`) for pushes to `main`, pull requests, manual `workflow_dispatch`, and a weekly Monday `06:00 UTC` staleness schedule. Every action is pinned to a verified commit SHA; `dist/skillspector-self-audit.sarif` is uploaded to GitHub Code Scanning from `ubuntu-latest` on non-fork runs when `github.event_name != 'pull_request_target'`.
- **Tag-Driven GitHub Release (`.github/workflows/release.yml`):** Triggered by pushing a `v*` tag (validated against semver format and `package.json` version) or manual dispatch (checking out `refs/tags/<input>` when a tag is provided). Runs `npm run verify:all` and `git diff --exit-code` on `ubuntu-latest`, generates and self-verifies `dist/SHA256SUMS.txt` over `dist/coldpin-{antigravity,claude,openai}.zip` and `dist/skillspector-self-audit.sarif`, and publishes the GitHub Release via built-in `gh release create` with least-privilege `contents: write`.

## Explicit Verification Boundaries (Not Claimed as Tested Locally)

1. **Live public npm / OSV.dev network calls:** Automated offline tests do not depend on live third-party endpoints. Run `node --no-warnings src/cli.ts inspect semver@7.7.1` on a networked host to verify live registry + OSV round-trips.
2. **Tier 3 Live Multi-Agent Sandbox Uplift:** Automated evaluation inside live Antigravity / Claude Code / Codex sessions with LLM token billing is not executed in offline local tests; `BENCHMARK.md` records Tier 3 as `NOT RUN (N/A)`.
3. **External Native Engines (`rea-agents`, `skillspector` binary, CI Sigstore Fulcio CA):** Treated as opt-in host or CI integrations; local `skill.oms.sig` uses an explicit `local-dev-self-signed` ECDSA P-256 verification key until signed in CI via Sigstore OIDC.
