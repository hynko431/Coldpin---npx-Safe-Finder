# Testing & Verification (`TESTING.md`)

`coldpin` enforces a 10-command automated local and CI verification pipeline (`npm run verify:all`, plus local `agy plugin validate --strict` and CI `git diff --exit-code` = 12 gates total) modeled on Google EGM, NVIDIA Auto-Ontology, NVIDIA SkillSpector, REA (`rea-ci-tests-audit`), and Enterprise Commons.

## Continuous Integration & Release Gates

- **Cross-Platform GitHub Actions CI (`.github/workflows/ci.yml`):** Executes `npm run verify:all` and checks `git diff --exit-code` across a `2 × 2` matrix (`ubuntu-latest` + `windows-latest` × Node `24` LTS + Node `26` Active LTS, `fail-fast: false`) for pushes to `main`, pull requests, manual `workflow_dispatch`, and a weekly Monday `06:00 UTC` staleness schedule. Every action is pinned to a verified commit SHA; `dist/skillspector-self-audit.sarif` is uploaded to GitHub Code Scanning from `ubuntu-latest` (Node `24`) on non-fork runs when `github.event_name != 'pull_request_target'`.
- **Tag-Driven Keyless Release (`.github/workflows/release.yml`):** Uses top-level `permissions: {}` with job-scoped least-privilege permissions and dry-run `outputs.release_tag != ''` guards. Runs `npm run verify:all` and `git diff --exit-code`, generates `dist/SHA256SUMS.txt`, attests SLSA build provenance (`actions/attest-build-provenance`), publishes GitHub Releases (`gh release create`), publishes to npm via keyless OIDC Trusted Publishing (`npm >= 11.5.1`, zero static tokens), and Cosign-verifies (`cosign verify-blob`) `mcp-publisher` before publishing `server.json` to the Official MCP Registry via GitHub OIDC.

## Explicit Verification Boundaries (Not Claimed as Tested Locally)

1. **Live public npm / OSV.dev network calls:** Automated offline tests do not depend on live third-party endpoints. Run `node --no-warnings lib/cli.mjs inspect semver@7.7.1` on a networked host to verify live registry + OSV round-trips.
2. **Tier 3 Live Multi-Agent Sandbox Uplift:** Automated evaluation inside live Antigravity / Claude Code / Codex sessions with LLM token billing is not executed in offline local tests; `BENCHMARK.md` records Tier 3 as `NOT RUN (N/A)`.
3. **External Native Engines (`rea-agents`, `skillspector` binary, CI Sigstore Fulcio CA):** Treated as opt-in host or CI integrations; local `skill.oms.sig` uses an explicit `local-dev-self-signed` ECDSA P-256 verification key until signed in CI via Sigstore OIDC.
