# Changelog

All notable changes to `coldpin` (Coldpin; originally drafted under working title `npx-safe-finder`) are documented here following [Keep a Changelog](https://keepachangelog.com/) and Semantic Versioning.

## [1.1.0] - 2026-11-19

### Branding & Naming
- **Renamed to Coldpin (`coldpin`):** Updated package, CLI binary (`coldpin`), multi-harness plugin manifests, canonical skill directory (`skill-src/coldpin/`), SARIF/CycloneDX tool metadata, SVG header, and documentation. Canonical policy file is now `.coldpin.policy.json` (with automatic backward-compatible fallback to `.npx-guard.policy.json`).

### Security & Hardening
- **Closed 8 Static Triage Evasion Vectors (`src/analysis/static-triage.ts`):** Added template-literal `${...}` expression lexing, `\uXXXX`/`\u{...}` Unicode escape decoding, regex-literal lexing (preventing `//` comment truncation), multi-hop intraprocedural taint propagation, receiver-aware network/DNS sinks (`dns.lookup`, `https.get`, `axios.post`, `net.connect`), `process["env"]` and `{ ...process.env }` / `Object.assign` detection, direct `child_process` dangerous command execution (`CHILD_PROCESS_DANGEROUS_EXEC`), `_0x` hex-identifier obfuscators, `String.fromCharCode` chains, and hex-encoded payload decoding.
- **Hardened Git Forensics & Tarball-Only Compromise Defense (`src/analysis/parity-and-bisect.ts`):** Disabled `.git/config` execution hooks (`core.fsmonitor=false`, `core.hooksPath=/dev/null`, `protocol.allow=never`, `diff.external=`), enforced strict `https://` remote URL validation (`CWE-88` argument-injection & SSRF defense), validated `gitHead`/`subdir`, preserved local Git drift checks even when `provenanceAttested=true`, and prevented tarball-only compromises with clean Git `HEAD` from emitting `USE_PINNED_LATEST`.
- **Hardened Archive & Network Boundaries (`src/quarantine/safe-unpack.ts`, `src/intel/registry-osv.ts`, `src/config/policy.ts`):** Added POSIX tar header checksum validation (`ARCHIVE_CORRUPT_HEADER_CHECKSUM`), byte-accurate POSIX PAX (`g` vs `x`, `size`, `linkpath` rejection), Windows illegal-character filtering, SSRF metadata-IP blocking, manual cross-origin redirect handling that strips private registry `Authorization` bearer tokens (`CWE-200`), multi-token private-scope query screening (`routeDiscoveryQuery`), and mixed-case `private_registries` normalization.
- **Enterprise Concurrency, Caching, Compliance & Observability (`src/cache/sqlite-store.ts`, `src/compliance/audit-log.ts`, `src/verdict/engine-and-formatters.ts`, `src/cli.ts`):** Added `SingleFlight` producer-once dedup, wired Split-Plane SQLite fact caching into `inspect`, added atomic lockfile serialization around `audit.jsonl` appends, added `--verbose` structured operational JSON logs on `stderr` and `--override-ticket`, upgraded CycloneDX 1.5 output with `serialNumber`/`dependencies[]`/VEX `vulnerabilities[]`, expanded local compromise detection to `pnpm-lock.yaml` & `yarn.lock`, added structured `rea_escalation_plan`, and wired OSV release/dep checks + alternative discovery into `resolve-anchor`.

### Governance & Reference-Repo Parity
- **Google EGM Packaging Parity (`scripts/pack_plugin.py`, `assets/icon.svg`):** Added root `assets/icon.svg`, unified `skills/coldpin/` layout across all three host bundles (`antigravity`, `claude`, `openai`), added automated packaged-archive manifest & relative Markdown link verification, added `--no-overwrite` refusal, removed legacy stale bundle zip, and added `SECURITY.md`, `CONTRIBUTING.md`, and `ACCESSIBILITY.md`.
- **Detection-as-Code & Self-Audit Rigor (`rules/triage-rules.json`, `rules/sigma/npx-suspicious-child-process-linux.yml`, `scripts/self_audit_skillspector.py`):** Added formal rule registry manifest, Linux/macOS CI Sigma rule, enterprise `.coldpin.policy.example.json` / `.npmrc.example`, and removed whole-file skips from SkillSpector self-audit with dynamic `fetch`/`execFileSync` line verification.
- **Expanded Verification (`tests/hardening-and-packaging.test.ts`, `tests/benchmark-corpus.ts`, `scripts/run_benchmarks.ts`):** Expanded corpus to 30 fixtures (15 benign + 15 adversarial), 8 real mutation proofs, warm-vs-cold cache effectiveness checks, and `BENCHMARK.md` dataset-digest freshness validation.

## [1.0.0] - 2026-11-19

### Added
- **Zero-Dependency Node 24 CLI (`src/cli.ts`)** implementing 5 canonical verbs (`discover`, `inspect`, `resolve-anchor`, `verify-confusion`, `audit-verify`) with exit codes `0 / 1 / 2 / 3`.
- **In-Memory Zero-Execution Tarball Quarantine (`src/quarantine/safe-unpack.ts`):** Streaming `node:zlib` byte-cap transform, SHA-512 verification, POSIX/PAX/GNU header parsing, Zip-Slip/symlink/hardlink/duplicate-entry/NTFS-ADS/Windows-reserved/case-collision rejection.
- **Deterministic JS/TS Lexical Taint & Hidden-Unicode Engine (`src/analysis/static-triage.ts`):** Single-pass $O(n)$ lexer, constant string folding, Base64 payload decoding, intraprocedural credential-to-network/exec taint, benign env allowlist, hidden/bidi Unicode & prompt-injection detection, native/WASM magic detection, and defanged IOC extraction.
- **3-Tier Tarball-vs-Git Parity & Patient-Zero Commit Bisect (`src/analysis/parity-and-bisect.ts`):** Provenance-first parity, manifest/hook parity, compiled `dist/` tolerance, `git diff-tree --root --first-parent`, full-tree blob-cached walk via Split-Plane SQLite (`WAL` + `busy_timeout`), and CVE/KEV dual-gate rollback.
- **Private-Scope Isolation & 7-Primitive Squat Shield (`src/config/policy.ts`, `src/discovery/slopsquat-guard.ts`, `src/intel/registry-osv.ts`):** `.npmrc` + `.coldpin.policy.json` private-first router, 1-edit/transposition typo block, and `verify-confusion` (`T1195.001`).
- **Enterprise Output Formats (`src/verdict/engine-and-formatters.ts`, `src/compliance/audit-log.ts`):** Sanitized `Title + Info + Evidence` Markdown cards, canonical JSON, SARIF 2.1.0, CycloneDX 1.5 SBOM, local workspace `package-lock.json` containment cards, and local hash-chained `audit.jsonl`.
- **Multi-Harness Enterprise Skill Package & Governance Suite:** Google EGM docs/manifests/reproducible packager, NVIDIA Auto-Ontology `runtime-contract.yaml`/`skill-card.md`/`BENCHMARK.md`/`skill.oms.sig`, NVIDIA SkillSpector self-audit (`scripts/self_audit_skillspector.py`), Enterprise Commons hygiene/staleness/Fact Ledger, and companion SOC Sigma rule.
