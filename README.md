Discover `npx` CLI packages by capability, category, creator, or organization without executing untrusted install scripts. **Coldpin** (`coldpin`) is a zero-dependency Node.js 24 CLI and multi-harness AI agent plugin.

**Deterministic CLI** fetches tarballs over HTTPS, verifies SHA-512 integrity, unpacks strictly in memory, runs linear-time JS/TS lexical taint and hidden-Unicode triage, checks OSV/OpenSSF `MAL-*` advisories, and validates 3-tier tarball-to-Git parity. **Safe-Anchor Resolver** walks release history and cached Git commits (`--first-parent`) to isolate the patient-zero commit and recover a verified pre-compromise release or vetted alternative. **You** review the `Title + Info + Evidence` card and decide whether to run any command.

## Install

Choose your coding agent or run the CLI standalone. Install the complete bundle so the skill can invoke `src/cli.ts` and read `references/` and `assets/runtime-contract.yaml`.

### Standalone CLI (Node.js `>= 24.0.0`, zero `npm install`)

```sh
git clone https://github.com/hynko431/Coldpin---npx-Safe-Finder.git
cd Coldpin---npx-Safe-Finder
node --no-warnings src/cli.ts --help
```

Or download a checksum-verified host bundle (`coldpin-{antigravity,claude,openai}.zip` + `SHA256SUMS.txt`) from [GitHub Releases](https://github.com/hynko431/Coldpin---npx-Safe-Finder/releases).

### Antigravity (Workspace / App / IDEs)

The workspace discovery mirror is generated by the reproducible packager into `.agents/skills/coldpin/`:

```sh
python scripts/pack_plugin.py --verify --sync-workspace
```

For manual global installation into `~/.gemini/config/plugins/coldpin/`, see [Harnesses](docs/harnesses.md#antigravity-app-and-antigravity-for-ides).

### Claude Code & Codex CLI

Build host-specific reproducible archives from this single source tree (no forked skill text):

```sh
python scripts/pack_plugin.py --target all --verify
```

See [Harnesses](docs/harnesses.md) for `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and marketplace catalog setup.

## Try your first audit

Run any step below directly from your terminal or ask your coding agent to invoke `coldpin`.

<img src="skill-src/coldpin/assets/icon.svg" width="20" height="20" align="top" alt=""> **1. Discover `npx` tools safely**

```sh
node --no-warnings src/cli.ts discover "json formatter" --category cli --limit 10
```

Screens candidates against org allow/deny policy, 7 typosquatting/slopsquatting mutation primitives, and release age cooldowns while routing private scopes exclusively to private registries.

<img src="skill-src/coldpin/assets/icon.svg" width="20" height="20" align="top" alt=""> **2. Inspect a package or offline tarball**

```sh
node --no-warnings src/cli.ts inspect prettier@3.5.3
node --no-warnings src/cli.ts inspect --tarball ./pkg.tgz --git-dir ./repo --offline --sarif
```

Emits a deterministic `Title + Info + Evidence` card (or `--json`, `--sarif`, `--sbom`) with exit code `0` (clean within scope), `2` (suspicious or unknown), or `3` (malicious indicators found).

<img src="skill-src/coldpin/assets/icon.svg" width="20" height="20" align="top" alt=""> **3. Recover a clean commit/release anchor**

```sh
node --no-warnings src/cli.ts resolve-anchor @org/tool --git-dir ./repo --window 200
```

Pinpoints the patient-zero commit, checks cached full-tree blobs across history, verifies CVE/KEV gates, and emits `ROLLBACK_TO_SAFE_ANCHOR` only when a verified npm tarball exists (otherwise `FORENSIC_COMMIT_ONLY` or `SWITCH_TO_ALTERNATIVE`).

<img src="skill-src/coldpin/assets/icon.svg" width="20" height="20" align="top" alt=""> **4. Audit dependency confusion & verify local audit trail**

```sh
node --no-warnings src/cli.ts verify-confusion ./package.json
node --no-warnings src/cli.ts audit-verify ./audit.jsonl
```
